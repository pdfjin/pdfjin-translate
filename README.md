# 📄 pdfjin-translate

> Translate PDF text into over 100 languages with formatting overlay by PDFJin by [PDFJin](https://pdfjin.com).

[![PyPI version](https://img.shields.io/pypi/v/pdfjin-translate.svg)](https://pypi.org/project/pdfjin-translate/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/downloads/)

Fast, private, and local document processing with zero size limits.

> 🌐 **Prefer a Web UI?** Use the free online browser tool at **[https://pdfjin.com/pages/translate-pdf.html](https://pdfjin.com/pages/translate-pdf.html)**.

---

## 📦 Installation

```bash
pip install pdfjin-translate
```

Or install from source:

```bash
git clone https://github.com/pdfjin/pdfjin-translate.git
cd pdfjin-translate
pip install .
```

---

## 🚀 Quickstart

Run via CLI:
```bash
pdfjin-translate --help
```

Use in Python:
```python
import pdfjin_translate
```

---

## 🧪 Testing

```bash
pip install pytest
```
